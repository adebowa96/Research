## Discrepancies to resolve

1. **Date limits were not applied the same way in every database.** 100 of the 516 records
   (in the EBSCO and PsycInfo exports) were published **before 2019**. The PubMed file starts
   at **2021**, not 2019. Scopus matches 2019–2026.
   - The manuscript currently says every search was "limited to January 2019 – March 2026".
     That is not accurate for EBSCO, PsycInfo, or PubMed as exported.
   - Honest options: (a) state that date limits were applied during screening, so the
     pre-2019 records sit inside the 327 excluded; and/or (b) re-run PubMed from 2019 so its
     range matches the other databases.
2. **The databases searched differ from the four named.** Women's Studies International was
   also searched. MEDLINE was searched twice (PubMed and MEDLINE Ultimate). CINAHL was
   searched through EBSCO. The Methods should list what was actually searched.
3. **Duplicate count.** Automated DOI and title matching across the four files finds about
   **192** duplicates (324 unique records). The manuscript reports **155** (361 unique).
   Reference managers match duplicates differently, so the automated number is only a check.
   Confirm the count in the tool you used (Zotero, Rayyan, Covidence, etc.).
4. **Search date.** The exports are dated March 29, 2026. Use this as the date the final
   search was run if the PubMed search was also run then.
