# Portfolio: Ifeoluwanimi Praise Shobayo

Personal portfolio website (MSPH Epidemiology). It is plain HTML and CSS with no build step.

- `index.html` is the home page
- `projects/` holds the case-study pages
- `assets/style.css` holds the shared styles

## Publish with GitHub Pages
1. Merge this branch into `main`.
2. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", then choose `main` and `/ (root)`.
3. The site will be live at `https://adebowa96.github.io/Research/`.
